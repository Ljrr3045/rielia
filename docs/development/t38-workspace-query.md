The old same-human recovery rule is superseded in this bounded client owner.
Authenticated memory binds verified user **and session**, with the original
captured recovery expiry. Temporary verification failure hides DTOs, draft/retry,
links and remembered labels/subjects. Same-session verification before that expiry
can restore the existing memory, retaining original versions/body/key; renewal
cannot extend the captured expiry. Same-human/new-session, account replacement,
actual expiry, logout/disabled identity and terminal401/403 erase the old private
lifetime, recovery, labels and secrets. Render masking precedes effects; retirement
masks the visible epoch before cancellation can revert Query data, then removes
actual records. Late success/denial cannot affect a replacement lifetime.

Select and unchanged props/cache freshness cannot reopen denial. Real config/session
and applicable selected-detail verification precede sibling reads/actions. Stale or
failed required resources block new submissions. Existing error-screen composition
and form/focus behavior remain; a stale Query projection does not authorize writes.
